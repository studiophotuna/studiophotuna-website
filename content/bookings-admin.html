Payment Gateway

Choose which payment gateway processes each type of payment on the site.

Plan Subscriptions

Used when a customer subscribes to a Studio Photuna Pro plan from the Account or Pricing page.

Event Booking Deposits

Used for the 50% deposit collected after a guest submits the Book an Event wizard.

PayMongo, Xendit, and PayPal are wired up for both Event Booking Deposits and Plan Subscriptions -- they still need their API credentials set as Supabase secrets to actually process a payment (selecting one before that falls back to manual payment instructions). For Plan Subscriptions specifically, only Stripe auto-renews; the other three (including Manual GCash) charge once per billing period and the customer resubscribes manually next time.
